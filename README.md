**Clone and prepare:**
```bash
git clone https://github.com/Rexrad/Cvfetch
cd cvfetch
chmod +x cvfetch.sh
```

**Edit the info:**
```bash
nano cvfetch.sh
```
Change the text between `${c2}` and `${rst}` inside the `info=(...)` block. Save with `Ctrl+O` then `Enter`, exit with `Ctrl+X`.

**Run it:**
```bash
./cvfetch.sh
```
